# email-manager

Simple microservice for an email manager, used alongside the [bookstore-data](https://github.com/Edu-Hiroshi/bookstore-data) repo.


## Dependencies

Spring Boot 4.1.1 

Java 21 LTS

## Setup

Example of dummy env variables to be added:
```
DATASOURCE_URL=jdbc:postgresql://localhost:****/****;
DATASOURCE_PASSWORD=****;
DATASOURCE_USERNAME=****;
MAIL_APP_PASSWORD=****;
MAIL_USERNAME=****;
RABBITMQ_ADDRESS=amqps://****.cloudamqp.com/****
```
